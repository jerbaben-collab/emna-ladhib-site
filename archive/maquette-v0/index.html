01Une approche humaine

Le progrès commence
par les bonnes questions.

Améliorer une organisation, ce n’est pas appliquer une recette toute faite. C’est prendre le temps d’observer le travail réel, d’écouter les personnes qui le font et de comprendre ce qui compte vraiment.

Mon approche mise sur la clarté, la collaboration et des améliorations concrètes — pour faire évoluer les façons de faire sans perdre de vue les équipes qui les font vivre.
